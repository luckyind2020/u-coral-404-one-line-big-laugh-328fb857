One Line, Big Laugh: a single hilarious one-liner that lands entirely on its own — a smart lock installed to keep burglars out that ends up locking its own owner out too.

## Run it

```sh
python3 main.py
```

This reads the line from `entry.txt`, validates it (exactly one line, at most 200 characters), writes it to `/output/entry.txt`, and prints it.
